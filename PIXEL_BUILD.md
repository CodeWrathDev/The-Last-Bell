# The Last Bell — Main Pixel Build

The original Phaser 2D pixel-art game is the primary playable build. It uses the authored maps in `src/maps`, the original decorations and doors, and the complete browser/mobile story systems.

Run it with:

```bash
npm install
npm run dev
```

Or use `tools/run_pixel_game.sh`.

Create a production browser build with:

```bash
npm run build
```

The Godot project remains available separately for the experimental 3D build.
